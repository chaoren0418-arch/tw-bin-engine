# P24 新版客戶端

本版已完成離線建置與程式檢查，尚待實機操作與線上驗收。啟動只顯示離線預覽，不會自動登入或啟動伺服器。

1. 雙擊「啟動新版客戶端.cmd」。需要本機已安裝 .NET 10 Desktop Runtime、Microsoft Edge WebView2 Runtime 及 PowerShell 7。
2. 輸入自己的帳號、密碼，按「登入」。預設連到本機遊戲伺服器 127.0.0.1:42061；伺服器需由管理者另外啟動。
3. 收到角色清單後選擇角色，按「進入世界」。沒有角色時不會自動建立。
4. 方向鍵或 WASD 移動；點選畫面目標後按 G 單次攻擊。從面板選魔法與對象後按 M 施法；選背包物品後按 U 穿卸／使用；選地面物品後按 P 拾取。
5. NPC面板可對話、買賣、學習技能及操作個人倉庫；交易前需相鄰且面對面，核對兩邊物品後手動確認。
6. 「取消／斷線」關閉連線；「離線預覽」回到預覽場景。F9開關網頁面板，F10回遊戲控制。網頁面板關閉或無法載入時，登入後可改用原生分頁操作。

帳號為1–12位英數字，密碼為1–13位不含空白的ASCII字元；本版不儲存登入密碼。

目前支援41組角色／武器外觀、13種職業性別外觀，以及初級治癒術、保護罩、光箭、神聖武器。男性妖精及部分武器／變身仍缺完整素材。地圖依已封裝資料載入，缺少素材時會停止並提示，不會替換成其他場景。不支援武器外觀時，仍可由背包請求卸下裝備或斷線。裝備、商店、倉庫、交易、生命及魔力的結果一律以伺服器回報為準。

建置與檢查（不開視窗、不連線）：

```powershell
pwsh -NoProfile -File .\build-product.ps1
pwsh -NoProfile -File .\launch-product.ps1 -CheckOnly
```

新版輸出在 build/client-product-r1，不覆蓋歷史 build/client。若啟動提示檔案變更，請重新建置，保留完整 assets 與 web 目錄。不要使用舊 build.ps1 建置此新版。
