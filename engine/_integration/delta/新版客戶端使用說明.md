# 新版客戶端 r28 使用說明

本版調整原生鍵盤導覽：Tab／Shift+Tab 交給原生控件切換焦點；登入帳密欄的 Enter 只經既有可登入狀態與按鈕執行一次。聊天輸入的裸 Enter 保留送出，其他欄位不會因 Enter 觸發登入。世界按鍵僅在遊戲場景實際取得鍵盤焦點時處理，F10 可明確回到遊戲。這些行為仍須以本版原生實測確認；離線規則檢查不代表實機焦點驗收。

雙擊同目錄「啟動新版客戶端.cmd」。入口顯示離線預覽，不自動登入或啟動服務。開啟登入面板後手動輸入帳號、密碼，再選角色進入世界；帳密欄位預設空白，不儲存密碼。帳號為 1–12 位英數、密碼為 1–13 位非空白 ASCII。連線固定使用本機 127.0.0.1:42061、profile `p24-real-jar-d287-client2`。一般啟動需要 Windows x64、.NET 10 Desktop Runtime 與 WebView2 Runtime；不需要 PowerShell。請保留同目錄 launcher 資料夾；同名 .cmd 先檢查 r28 版本、必要檔案及 runtime，再以正確工作目錄啟動。

登入角色後，正常畫面顯示場景、HP／MP、角色狀態與四格快捷列。下方「背包／裝備／技能／聊天／服務」可開啟相應內容；NPC、商店、倉庫、交易與私商回覆會顯示在正常服務窗，不必開診斷面板。F9 開關診斷面板，F10 回到遊戲控制，F11 仍是記事欄。

左鍵點地面沿已載入的可通行路徑行走；過遠、無路、被擋或狀態改變會停止，不會自動追擊。左鍵可見目標只選取，雙擊或 Ctrl＋左鍵單次攻擊，右鍵單次交談。單擊地上物品選取，雙擊單次拾取 1 件；需要走近，沒有自動追物或重送。右鍵空地、Esc 或空白鍵停止後續滑鼠動作；已送出的請求仍依伺服器處理。正常 HUD 會顯示移動／拒絕／送出提示，送出不表示成功。

四格快捷列可點擊或用 F1–F4 執行一次，按住不連發。先選背包道具或已學技能，再選快捷格指派；可清空。配置在本程序內依角色保留，同角色重登保留，關閉程序後不保存。選取道具不會使用，按「使用／穿卸」才操作；技能保留目前四項支援範圍，未支援項目明確標示。道具數量、HP／MP、裝備狀態依原服回報更新。

聊天區只提供一般聊天，輸入單行 1–52 字，按 Enter 或「送出」提交；聊天歷史只顯示伺服器回傳，不先加入本地訊息。遊戲字集不能表示的字元會被拒絕。聊天或其他輸入欄位聚焦時不觸發移動、施法或攻擊；先按 F10 恢復遊戲控制。點擊 HUD／服務窗不會穿透到場景。

仍可使用方向鍵／WASD 移動，Home／PageUp／End／PageDown 為畫面斜向；畫面上方是世界方向 D1，左上是 D0。轉向數字 1–8 採原世界方向。G 單次攻擊選取目標，M 施放選取技能，U 使用選取物品，P 拾取選取地上物。NPC 對話、購物、倉庫及直接交易仍需要明確選擇與確認。使用 HUD「登出」或登入列「取消／斷線」關閉連線。

本版加入現有人物空手／長劍／匕首與已遇 NPC 的原素材陰影，並保留 SPR 空白像素透明；沒有核實素材的外觀不以近似圖替代。

能力點面板可手動查詢分配狀態。收到原服提示後，明確選取力量、敏捷、體質、智力、精神或魅力之一，再確認一次；沒有預選、補點或自動重送。剩餘點數是「原服未提供」，沒有回覆不代表零點。顯示的能力值可能含裝備與效果；收到數值更新不等於持久化確認，請重新登入核對。

個人商店需先選取可見店主，再明確查詢「買入」或「售出」清單；選一列、輸入有效數量並確認一次。清單不自動選列或數量。買入列保留伺服器原始順序；售出依目前持有物件、數量及裝備狀態檢查。清單未提供貨幣種類，收購數量也不保證是店主剩餘需求。送出完成只代表本地傳送步驟完成，普通訊息與背包更新都不等於整筆成交確認。若提示「可能已送出／結果未知」，先核對物品與貨幣，不可當成未送出而直接重試；系統不會自動重送。

查詢逾時，或完整清單回來前關閉面板／店主或世界失效，同一連線的「店主＋買入或售出模式」會保持不確定狀態。關面板、換目標或走回原位不能解除；須正常重新連線後，再明確選店查詢。其他店主或另一模式分別判定。此規則無法辨識晚到回包，也不提供鎖價保證。不支援開攤、拍賣或離線擺攤。

地圖、角色、武器、怪物外觀與四種魔法均限已封裝內容；缺少素材時會提示並限制相應操作。店主 gfx6661／6650／1186 使用已封裝原始 action70 外觀。旅館門 gfx2346 依已知 28／29 狀態顯示開關，未知、死亡或等待狀態不假造姿勢；不新增開門請求、打門或 S209 通行碰撞處理。旅館沒有原服退租 handler 的情形，不提供虛構退租或退款。

請保持 `build/client-product-r28`、`web`、`assets` 與 `build/product-r28-manifest.json` 成套使用；不要混入 r16、r17 或其他候選檔案。正常 Web 日誌位於 `runs/interactive-PID`，WebView2 使用者資料位於 `runtime/session-PID`；這些是可變執行資料，不是封存輸入。

只讀入口核對：在本目錄的命令提示字元執行 `".\啟動新版客戶端.cmd" --check-only`；只檢查，不啟動遊戲，也不需要 PowerShell。

開發者從來源建置（此途徑需既有 PowerShell 7，一般使用者的啟動與只讀核對不使用它）：`pwsh -NoProfile -File ./build-product.ps1`。請在新的工作副本進行，勿覆寫已封存交付或執行中的檔案。SDK 固定 10.0.300，NuGet 使用隨附 vendor；Release PDB 保留，虛擬來源根為 `/_/p24/source`，除錯時對應至本交付 source。Debug 保留本機來源路徑。啟動器固定核對本次 r28 manifest；重建若改變 manifest，需重新審核啟動器版本識別。

普通已鑑定肉與普通回家卷軸可在背包明確選取後，按使用按鈕或 U 單次使用；高飽食吃肉仍可能消耗。其他食物、未鑑定版本與其他卷軸未開放。回城位置由原服決定，部分地圖禁止使用；不預先扣數量或移動角色。回報未齊時暫停後續操作，15 秒後仍明示不確定，請取消連線後重登入核對，不會自動重送。飽食 /255 與負重 /240 為原服刻度。請成套更新 Web 與客戶端，避免舊頁選取資料被拒絕。背包、魔法與交易提示在顯示時解析原服物品名稱，協議與原始訊息記錄保持原文。

本版補齊實際遇到的紅寶石（圖示242）與純粹的米索莉塊（圖示318）原始背包／Web圖示。物品使用與交易行為保持不變；請以新啟動的同版客戶端查看既有物品，舊程序可能已快取缺圖。

本版聊天：在可正常聊天的世界狀態下，遊戲場景按 Enter 或按聊天按鈕會直接聚焦聊天輸入；開啟所用 Enter 必須放開，再按下一次 Enter 才提交，長按不連發。Escape 收起聊天並回遊戲，保留未送草稿。聊天結果仍只依原服回傳。

本版原陰影涵蓋目前已封裝的 13 種人物、42 組外觀，含原有匕首及 gfx0 弓／雙手劍所需影格；未封裝職業／武器沒有借用其他影子。既有 NPC 陰影與 SPR 透明修正保留。


## 聲音設定

玩家「服務 → 聲音」與本機網頁面板共用主音量與靜音。預設音量 50%；設定顯示已套用前須等待客戶端回覆。靜音、暫不可用及缺件事件不會稍後補播；登出或關閉會停止本模組音訊。此版只封裝 6016 的兩個原 WAV，MP3 仍缺件，未宣稱原 Miles 音量或距離等價。
