## 自動盟徽查詢（原版 `sub_81F210`／`sub_81EDD0`／`sub_81F390`）

- 繪製需要盟徽、但快取沒有時，`LoginConnection.RequestClanEmblem(id)` 送 C72。同一 id 待回覆中不再送；最多 32 筆待回覆；收到 S118（成功或無法解析）都釋放名額。無法解析的 id 在本連線不再要求。送出 gate 拒絕（未上線）時釋放名額，之後可再送。新連線（`generation` 改變）時清掉舊連線的待回覆。
- 要求的 id 是物件的 S87 `clanId`（原版 +212 同時是血盟 id 與盟徽 id）。**已知伺服器差異**（見 `clan.md` 第 3、4 項）：3.81 伺服器 `C_Clan` 用 `L1Clan.getEmblemId()` 比對；若伺服器的 emblem id 不等於 clan id，就不會回覆，引擎依原版不重送。上傳盟徽時伺服器以 clan id 廣播 S118，仍可填入快取。
- 記憶體快取 512 筆，滿了換掉最久沒用的一筆。快取跨換圖與重新連線保留（原版是跨連線磁碟快取），不再依 `WorldEpoch` 清除。
- 磁碟快取：`<engine>/runtime/user/emblems.bin`（`engine/runtime/` 不入 git），格式 `TWEM`、版本 1、`H` 筆數、每筆 `D id`＋192 個 ARGB `D`，最近使用的在前。讀檔失敗或格式不符就忽略。**不寫原客戶端目錄。**
- 「全部顯示名稱」選項存在同一目錄的 `name-display.txt`（專案原本沒有本機設定檔可以沿用）。

## 繪製（`ObjectRendering.cs`）

- 平常只畫滑鼠指到的物件：稱號（+240 非空）在 `T−3`，名稱在 `T−3`（有稱號時 `T+10`）；有血盟 id 時名稱右移 10、盟徽在名稱基準 −20、`T−4`（有稱號再 +13）；隊伍成員且非自己再 −9。X0＝L＋(W−6·Big5 bytes)/2。
- 「全部顯示名稱」：所有可見物件畫名稱（`T−16`），不畫稱號；戰爭中的本盟／敵盟角色（+196）不畫。
- 頭上盟徽 16×12：自己有血盟時畫在同盟成員頭上；戰爭中另畫在敵盟成員頭上；位置 `L+(W−16)/2`、`T−23`。
- 字型 MingLiU 12 px（粗細 400），上下左右 ±1 px 畫黑色外框，再畫名稱色；稱號與名稱同色。座標以場景像素計算，隨相機縮放。
- 名稱顏色：gfx 2715 且非戰爭 → `0x7C00`；粉紅 → `0x767D`；否則正義值公式（2.4）。決鬥對手、敵對血盟不改色。
- 移除引擎多畫的「名稱 [血盟]」、「決鬥對手 · 名稱」、敵盟紅底標籤、頭上 HotPink 粉紅名、目標「名稱 #id」金字。
- 可直接攻擊（`sub_A3FE30`）：粉紅名、決鬥對手、敵對血盟（+197＝2）。滑鼠指到時游標改為十字（系統游標代用，原版游標圖未載入），左鍵單擊即送攻擊（`PlayerPointerUi.cs` 加一個條件）。
