## 主要結論（已驗證）

1. **日夜：**
   - 曲線：06:00–06:40 變亮，06:40–20:00 等級 15，20:00–20:40 變暗，其餘時間等級 1。每幀再加 1，所以夜晚的實際等級是 2。
   - 修正：地圖 id 覆寫、妖精系 +2（職業對應屬推測）、雨雪 −1、特效暫時 +5。
   - 套用方式：用 3×16×32 的係數表（`0x1374168`）逐色頻相乘。夜晚未照亮處的亮度約 10/31。
   - 客戶端不自行推進時鐘。
2. **天氣：**
   - 解碼：高半位 0 是雨、0x10 是雪；強度 1–3，>3 視為 0。
   - 雨 128／256／512 顆，分 4 層（2 層 Surf 圖、2 層程序水花）；雪 48／96／144 顆，雪花是程序繪製。
   - 地圖 7701–7710、7771–7780 強制下雨。
   - 雨雪先畫，夜晚的明暗會一起壓暗它們。
3. **光源（S40）：**
   - 自己的光源值 <5 視為 5；19／20 會順帶提高全域亮度；別人的 20 視為 5。
   - 光源圖是 `source.lmp` 的 16 張圖，以取最大值的方式合成在 400×240 光照圖上。每幀預算為光源值總和 700，只處理 ±35／±15 範圍內的物件。
4. **狀態外觀：**
   - 中毒：只在綠色頻加 8–14，三角波週期 1.2 秒。
   - 麻痺：`c/2+(3,3,3)`；同時中毒時灰優先。
   - 盲目 1：全黑，只剩自己周圍光圈。盲目 2：接近全暗，特定種類物件仍發光。
   - 酒醉：逐掃描線水平正弦波，振幅 3.5×醉度，5 秒一輪。
   - 隱身：自己以 50% 混合顯示；別人預設不畫。
5. **`^`：**
   - 物件進入新影格時觸發，交給 Miles 以次數 0 播放。
   - 每個音效 id 全場最多 5 個近距音源，依距離排序，滿了才換入更近的。
   - 同 id 正在播時不重播；冷卻 200 ms。
   - 每幀依距離更新音量，曼哈頓距離 >14 時為 0；離開範圍不會停止，只有釋放或被擠掉時才停。
6. **與引擎的差異：** 共比 21 項，一致 3 項、部分一致 3 項、不一致 15 項，見文件第 7 節。

## 怎麼驗證

- 每個結論都有對應的 Hex-Rays 偽碼函式。關鍵的參數順序（`S_POISON` 的 `dcc`）用 Capstone 反組譯確認推入順序。
- 用 IDA 的 xref 類型確認全域變數的寫入者：時鐘只有 `S_STATUS` 與 `S_TIME` 兩處寫入。
- 磁碟上的表（明暗表、灰色常數 `0x0C630C63`）用 pefile 直接讀出。
- TW13 交叉驗證：明暗表模式 0／1 與 TW13 逐位元組相同；雨量 128／256／512 的指令序列也在 TW13 找到。
- 所有引用的地址都由 `va2off.py` 換算 File Offset，不是手算。
