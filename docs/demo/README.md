## 還差什麼

本輪仍需處理以下項目；既有追蹤以 [TASKS.md](../../TASKS.md) 為準，以下任務範圍對照不代表已定位根因：

- 完整遊戲流程、原生畫面／滑鼠／HUD／聊天焦點：T011、T023。
- NPC 服務、換圖連續性、場景音訊：T020～T022。
- 技能擴充、Slow 速度拾取／丟棄、地圖效果與可攜交付：T030～T033。
- T011／T023：物件占位、UI 座標核對、鍵盤 16 筆條件、點地終點、移動目標選取、聊天回顯，以及卸裝完成後截圖。
- T030～T033：金幣 1／10 枚丟撿循環未成立；0／33401 的拒絕訊息同時提到數量與重新選取，尚未隔離數量驗證和選取失效的原因。
- 戰鬥與技能：尚缺近戰減血／死亡及 EXP 增加、光箭成功施放、非滿血的治癒術與藥水回血差值。
- 音效：已驗證程序靜音切換，尚缺有效目標攻擊與各事件音效的獨立對應；未做人工聽覺判定或 MP4 錄影。
- 交付：GitHub 在收尾時回報 PUBLIC；本次含實機證據的提交先留本機，交總控確認交付可見性，不變更儲存庫設定。
