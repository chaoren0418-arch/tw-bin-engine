- 候選共 80 檔（78 PNG、2 log），原始合計 65,963,294 bytes；全部單檔均不超過 2,000,000 bytes。

- 全部 78 張 PNG 已逐張以原圖目視確認，未見密碼欄明文；登入／診斷畫面的帳密欄為空。文字掃描不等同 OCR，圖片結論來自逐張目視。

- `server.stderr.log` 僅含 Java Security Manager 警告；不能作為移動、戰鬥或退出程序的完整證明。
